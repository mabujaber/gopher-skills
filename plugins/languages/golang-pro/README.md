# golang-pro

Claude Code plugin for Go language development — idiomatic patterns, concurrency, testing, gRPC, browser automation, and DBOS durable workflows.

## Skills

| Skill | Description |
|-------|-------------|
| `golang-patterns` | Idiomatic Go patterns — error wrapping, interface design, package layout, functional options, sync.Pool, strings.Builder, golangci-lint setup, and common anti-patterns. |
| `go-concurrency-patterns` | Concurrent Go applications — worker pools, race conditions, deadlocks, goroutine leaks, channel patterns, sync.WaitGroup, errgroup, context cancellation, and -race detector. |
| `golang-testing` | Go tests, coverage, benchmarks, fuzzing, and flaky test debugging — table-driven tests, subtests, golden files, httptest, and mocks. |
| `grpc-golang` | Protobuf contracts with Buf, gRPC services in Go, mTLS, unary and streaming RPC handlers, buf lint/generate/grpcurl errors, and OpenTelemetry interceptors. |
| `dbos-golang` | DBOS durable workflows in Go — workflows, steps, queues, events, messages, streams, DBOS Client, and testing DBOS applications. |
| `go-playwright` | Browser automation and web scraping with playwright-go — stealth/anti-bot evasion (Cloudflare, Akamai), session reuse, and network interception. |
| `go-rod-master` | Browser automation with go-rod (Chrome DevTools Protocol) — stealth anti-bot detection, request hijacking, page pools, and headless Chrome lifecycle. |

## Commands

| Command | Description |
|---------|-------------|
| `/go-build` | Diagnose and fix Go build errors, compile failures, and dependency issues. |
| `/go-review` | Review Go code for correctness, idioms, performance, and security. |
| `/go-tdd` | Drive test-driven development in Go — write failing tests first, then implement. |

## Agents

| Agent | Description |
|-------|-------------|
| `golang-pro` | Senior Go engineer agent — implements features, refactors code, and applies idiomatic Go patterns. |
| `go-reviewer` | Go code reviewer — checks for correctness, idioms, concurrency safety, and test coverage. |
| `go-build-resolver` | Build failure resolver — diagnoses compile errors, module issues, and dependency conflicts. |

## Installation

```bash
/plugin install golang-pro@gopher-skills
```
