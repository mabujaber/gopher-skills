# temporal-developer

Build, debug, and manage Temporal applications across Python, TypeScript, Go, and Java.

## Installation

```bash
/plugin install temporal-developer@claude-code-plugins-plus
```

## Usage

This plugin provides the `temporal-developer` skill. Use it when:
- Building Temporal workflows, activities, or workers
- Debugging non-determinism errors, stuck workflows, or activity retries
- Working with Temporal CLI, Temporal Server, or Temporal Cloud
- Implementing signals, queries, heartbeats, saga patterns, or workflow versioning
- Integrating AI/LLM agents with Temporal's durable execution

## Languages Supported

- Python
- TypeScript
- Go
- Java
